# ДОМЧ ам зайлагч — landing page

Жамц давсны уусмал ДОМЧ-ийн танилцуулга хуудас. Сав хуудсыг гүйлгэх үед 3D-ээр хөдөлж, эргэлдэнэ. Найрлагын хэсэгт давсны талст, хандны дусал, гааны навч савыг тойрон эргэлдэнэ.

## Бүтэц

- `index.html` — хуудас бүхэлдээ (HTML, CSS, JavaScript)
- `assets/` — шошгын зураг болон савны зураг

3D хэсэг нь Three.js 0.160.0-ыг jsDelivr CDN-ээс ачаална. Build хийх шаардлагагүй.
3D ажиллахгүй төхөөрөмж дээр савны зураг хэвээрээ харагдана.

## Нийтлэх

**GitHub Pages:** Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, folder: `/ (root)` → Save.

**Vercel:** repo-г import хийнэ. Framework preset: *Other*. Нэмэлт тохиргоо хэрэггүй.

**Компьютер дээр үзэх:** хавтас дотроо `python3 -m http.server` ажиллуулаад `http://localhost:8000`-г нээнэ.
`index.html`-г шууд давхар товшиж нээвэл 3D модуль ачаалагдахгүй.

## Бөглөх мэдээлэл

Хуудсанд `[ ]` хаалтанд үлдээсэн зүйлс:

- Үнэ (250 мл, 500 мл)
- Хэрэглэх хэмжээ, зайлах хугацаа, хүүхдийн насны заалт, хадгалалтын нөхцөл (шошгоор баталгаажуулах)
- Эмчийн зөвлөгөө, контент бүтээгчдийн нэр, видео
- Худалдаалах цэг, эмийн сангийн сүлжээ, онлайн дэлгүүрийн холбоос
- Холбоо барих мэдээлэл, сошиал холбоос

## Тэмдэглэл

- 3D сав нь бүтээгдэхүүний зурагт тулгуурласан ойролцоо загвар. Дизайнерын 3D файл (`.glb`) байвал түүгээр сольж болно.
- Савлагааны хэмжээг 250 мл / 500 мл гэж оруулсан. Хөгжүүлэлтийн гайдад 200 мл гэж бичсэн тул шалгаж баталгаажуулна уу.
